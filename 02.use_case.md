#### Variable Dependiente (Y): Ventas
- **Rango:** 120.50 a 565.00 (miles de USD)

## 4. MODELO ENTREÑADO


### Análisis de la Pendiente (14.7260)

#### Significado Matemático
- **Interpretación:** Por cada unidad (miles USD) adicional en publicidad, las ventas aumentan en 14.7260 unidades (miles USD)
- **Rendimiento:** Cada $1,000 invertidos en publicidad generan $14,726 en ventas
- **ROI directo:** Retorno de inversión ≈ 1,372.6% (ignorando otros costos)

#### Implicaciones Comerciales
1. **Eficiencia Publicitaria:** La publicidad tiene un impacto muy alto
2. **Punto de Equilibrio:** 
   - Inversión = 0 → Ventas base = 52.0977 (miles USD)
   - Cada dólar invertido genera 14.73 veces su valor
3. **Escalabilidad:** El modelo sugiere que se puede escalar la inversión
4. **Margen de Mejora:** Potencial para optimizar inversión

#### Consideraciones sobre la Pendiente
- **Validez:** Asume relación constante en todo el rango
- **Límites:** No considera saturación de mercado
- **Sostenibilidad:** Relación tan alta podría no ser sostenible
- **Otros Costos:** No incluye costos de producción u operativos
