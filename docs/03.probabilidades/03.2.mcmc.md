#  Markov Chain Monte Carlo (MCMC)

Un método de **Markov Chain Monte Carlo (MCMC)** se utiliza principalmente en la _estadística bayesiana_ para obtener muestras de una distribución de probabilidad compleja cuando no es posible calcularla directamente de forma analítica. 

A continuación, tienes un ejemplo práctico implementando el algoritmo clásico de **Metropolis-Hastings** (el tipo de MCMC más fundamental) utilizando únicamente las librerías científicas estándar de Python (`NumPy` y `Matplotlib`).

## 💡 Ejemplo Práctico: Muestrear una Distribución Normal

En este ejemplo, nuestro **objetivo** es simular que queremos obtener muestras de una distribución objetivo (una campana de Gauss o distribución Normal con media 0 y desviación estándar 1), pero "fingiendo" que solo conocemos su forma y no cómo generar números aleatorios directamente desde ella.

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. Definimos la distribución objetivo (Target)
# En estadística bayesiana, esta sería la distribución a posteriori (posterior)
def target_distribution(x):
    # Distribución Normal estándar (sin la constante de normalización)
    return np.exp(-0.5 * x**2)

# 2. Parámetros de la simulación MCMC
num_samples = 100000       # Número total de iteraciones
samples = np.zeros(num_samples)
current_x = 0.0            # Estado inicial de la cadena de Markov
samples[0] = current_x

proposal_width = 0.5       # Qué tan grande es el paso aleatorio (desviación estándar)

# 3. Algoritmo de Metropolis-Hastings (MCMC)
for i in range(1, num_samples):
    # Proponer un nuevo candidato usando un camino aleatorio (Random Walk)
    proposed_x = current_x + np.random.normal(0, proposal_width)
    
    # Calcular la probabilidad de aceptación (current_x = actual, proposed_x = propuesto)
    p_current = target_distribution(current_x)
    p_proposed = target_distribution(proposed_x)
    
    # Evitar división por cero si p_current es extremadamente bajo
    acceptance_ratio = p_proposed / max(p_current, 1e-10)
    
    # Aceptar o rechazar el candidato
    if np.random.rand() < acceptance_ratio:
        current_x = proposed_x  # Aceptado: la cadena se mueve
    # Si se rechaza, current_x se mantiene igual (la cadena no se mueve)
        
    samples[i] = current_x

# 4. Visualización de los resultados
plt.figure(figsize=(12, 5))

# Gráfico 1: El camino de la cadena (Trace Plot)
plt.subplot(1, 2, 1)
plt.plot(samples[:1000], lw=0.5, color='teal')
plt.title('Camino de la Cadena de Markov (Primeras 1,000 muestras)')
plt.xlabel('Iteración')
plt.ylabel('Valor de X')

# Gráfico 2: Histograma de las muestras obtenidas vs. Distribución Real
plt.subplot(1, 2, 2)
x_axis = np.linspace(-4, 4, 500)
# Distribución real normalizada para comparar
true_pdf = (1 / np.sqrt(2 * np.pi)) * np.exp(-0.5 * x_axis**2)

plt.hist(samples, bins=50, density=True, alpha=0.6, color='g', label='Muestras MCMC')
plt.plot(x_axis, true_pdf, 'r--', lw=2, label='Distribución Real (Objetivo)')
plt.title('Distribución de las Muestras Generadas')
plt.xlabel('X')
plt.legend()

plt.tight_layout()
plt.show()

```

## 🔎 ¿Cómo funciona este código paso a paso?

1. **El Estado Inicial:** Empezamos en un punto arbitrario (`current_x = 0.0`).
2. **La Propuesta (Proposal):** En cada iteración, sumamos un pequeño ruido aleatorio normal (`np.random.normal(0, proposal_width)`) al estado actual para proponer un nuevo valor (`proposed_x`).
3. **El Criterio de Aceptación:**
    
    1. Si el nuevo punto está en una zona de _mayor probabilidad_ que el anterior (`p_proposed > p_current`), se acepta siempre.

    2. Si el nuevo punto está en una zona de _menor probabilidad_, se acepta con una probabilidad proporcional a qué tan malo sea (`p_proposed / p_current`). Esto permite que la cadena explore todo el espacio sin quedarse estancada en el pico más alto.

4. **Almacenamiento:** Si se acepta, el nuevo estado pasa a ser el actual; si se rechaza, el estado actual se repite en el historial.

## 🛠️ Librerías avanzadas para producción
Si estás resolviendo problemas complejos de ciencia de datos o inferencia bayesiana en el mundo real, no programes MCMC desde cero. Existen librerías maduras y altamente optimizadas que utilizan algoritmos avanzados como **HMC (Hamiltonian Monte Carlo)** o **NUTS**:

* **[PyMC](https://www.pymc.io/)**: Es la librería estándar de facto en Python para el modelado probabilístico bayesiano.
* **[Stan (CmdStanPy)](https://mc-stan.org/cmdstanpy/)**: Excelente interfaz para usar el motor Stan, el cual es increíblemente rápido y robusto para modelos complejos.
* **[ArviZ](https://arviz-devs.github.io/arviz/)**: La herramienta compañera perfecta para analizar y graficar las "trazas" (diagnósticos) resultantes de tus cadenas MCMC.
